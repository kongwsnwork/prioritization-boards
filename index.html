Cheat Sheet

หลักการเบื้องหลังบอร์ดนี้

บอร์ดนี้ใช้ 2 เฟรมเวิร์กทำงานคู่กัน โดย MoSCoW ช่วยตัดสินว่า "อะไร" ควรทำก่อน ส่วน Make It Work / Right / Fast ช่วยตัดสินว่าพอเลือกแล้วควรลงมือ "อย่างไร"

MoSCoW จัดลำดับ "อะไร"

M

Must (ต้องมี)

ขาดไม่ได้ ถ้าไม่มีถือว่า release นี้ล้มเหลว จึงต้องทำก่อนเสมอ

S

Should (ควรมี)

สำคัญแต่ไม่วิกฤต มี workaround ชั่วคราวได้ถ้าจำเป็น

C

Could (มีก็ดี)

อยากได้ แต่ผลกระทบน้อยถ้าไม่มี จึงตัดออกก่อนได้เมื่อเวลาจำกัด

W

Won't (ยังไม่ทำ)

ตกลงแล้วว่ารอบนี้ไม่ทำ บันทึกไว้เผื่ออนาคต กัน scope creep

เลือกอะไรก่อน → แล้วค่อยลงมือทำอย่างไร

Make It Work → Right → Fast ลงมือ "อย่างไร"

1

Make It Work

ทำเวอร์ชันง่ายที่สุดที่ใช้งานได้จริงก่อน ยังไม่ต้องสมบูรณ์แบบ

→
2

Make It Right

ปรับให้ถูกต้อง รัดกุม ดูแลรักษาได้ในระยะยาว

→
3

Make It Fast

ปรับให้เร็ว/มีประสิทธิภาพขึ้น เฉพาะจุดที่จำเป็นจริง

นี่คือความหมายของจุด W / R / F บนการ์ดแต่ละใบด้านบน บางงานไม่จำเป็นต้องไล่ครบทั้ง 3 ขั้น ใช้ติ๊ก "เสร็จแล้ว" ที่ตัวการ์ดแทนได้เลยเมื่องานจบจริง ๆ
