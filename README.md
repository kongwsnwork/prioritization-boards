# Prioritization Boards

A single-file, no-build web tool for prioritizing requirements with **MoSCoW**
(Must / Should / Could / Won't) and tracking execution with **Make It Work →
Make It Right → Make It Fast**.

Supports multiple boards, drag-and-drop between MoSCoW columns, and export to
Markdown, Word (`.doc`), and JSON (for backup/restore).

## Usage

Open `index.html` directly in a browser — no server or build step needed.
Data is stored in the browser's `localStorage`, scoped to wherever the page
is hosted/opened from.
